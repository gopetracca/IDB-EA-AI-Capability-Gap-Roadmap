# Review returns

Completed review workbooks land here, dated, one file per return:

    2026-09-xx-taxonomy-<reviewer>.xlsx
    2026-09-xx-provenance-<reviewer>.xlsx

Never edit a returned file. Read the decision columns, apply the accepted changes to
`model/model3.json` or `build/prov_data.py`, rebuild into `out/`, and record anything that settles
a question in the Project decisions doc.
